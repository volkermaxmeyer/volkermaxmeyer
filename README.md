# Hi, I'm Volker 👋

I'm a **Service Designer and Product Leader** based in Berlin. I work at the intersection of **service design, product strategy, and AI-augmented building** — turning discovery and strategy work into shipped prototypes with [Claude Code](https://www.claude.com/product/claude-code), without a classic engineering background.

The repositories pinned here are things I built and use. Each README says which problem it solves, how it was built and where it stands.

## 🔭 What I'm working on

- **Product & Service Strategy:** product vision, North Star metrics, strategic narratives — most recently for an Industrial IoT / B2B SaaS platform
- **AI-augmented PM workflows:** building my own tooling for context engineering, automated briefings, and live prototyping on top of Claude Code + MCP
- **Human-centered research:** discovery, journey mapping, and organizational transformation for teams building product culture
- **Ship-first learning:** a monthly build brief with d.AI, the Design AI Academy (formerly AI Makers Club)
